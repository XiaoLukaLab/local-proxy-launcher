01 / SCOPE它适合谁？

适合尝试

已安装并正常登录官方客户端；本机代理可以访问 Google；普通代理模式下模型加载失败，开启 TUN 后情况改善。

不处理的情况

账号资格或地区被服务端拒绝、额度耗尽、官方模型故障、未安装客户端，以及只有 SOCKS 或必须认证的远程代理。

本工具解决的是特定网络传输路径。不能保证所有 VPN、所有客户端版本或所有模型都可用。

02 / BEFORE YOU BEGIN准备与解压

  1. 使用 Windows 10 或 Windows 11。已实测的是 Windows 10 x64；Windows 11 尚未实机验证。
  2. 从官方渠道安装 Antigravity，并由你本人完成登录。启动器不读取或代管账号凭据。
  3. 打开你已经使用的 VPN 或本地代理，确认有可用的 HTTP/Mixed 端口。不需要购买本工具配套服务。
  4. 将收到的 LocalProxyLauncher-v1.0.0-beta.1-Windows.zip 保存到本地，右键选择「全部解压」。不要在 ZIP 预览中直接运行 BAT。
  5. 解压目录可以包含中文和空格。不要只复制 BAT；保留 scripts 与 docs 等完整结构。

03 / NETWORK MODEVPN 开启，TUN 可以保持关闭

保持你已有的 VPN 开启，并按自己的日常规则模式运行。TUN 会接管更广的系统流量；本工具通过本地 HTTP CONNECT 代理给 Antigravity 提供独立出口，目标是在 TUN 关闭时工作。

启动器不会开关 TUN、切换节点、修改分流规则或配置全局代理。如果关闭 TUN 后代理本身不能访问 Google，应先解决 VPN 的连接问题。

仅有 PAC 自动配置、远程认证代理或 SOCKS-only 端口时，可能无法自动使用。不要把 VPN 管理端口当成代理端口。本工具会实际验证 CONNECT 和 TLS。

04 / INSTALL一键部署，等待明确结果

  1. 双击 01 一键部署.bat。通常不需要管理员权限。
  2. 程序依次检查系统、官方客户端、本地代理、Google TLS 连接，然后复制运行文件并创建两个桌面入口。
  3. 自动识别不到客户端时，可按提示填写已安装的 Antigravity.exe 路径。自动找不到可用代理时，按提示填写本地地址和端口。
  4. 看到「部署完成」后才算安装成功。看到「部署失败」则按原因处理，不能只看目录或快捷方式是否出现。

日常文件保存在 %LOCALAPPDATA%\LocalProxyLauncher。该位置由 Windows 为当前用户确定。桌面入口指向这里；部署成功后可以删除原始解压目录。

重复部署会复用同一安装目录和两个固定名称的桌面入口。已有有效配置优先验证并保留；变更前保存一份 config.previous.json。不覆盖同名但属于其他目标的快捷方式。

端口发现有数量与时间上限。一般只需数秒；网络异常、候选端口较多时可能需要约 3 分钟。不会无限等待。

05 / DAILY USE以后从桌面启动

  1. 确认 VPN 开启，且本地代理可用。
  2. 等待客户端任务和官方更新结束，从菜单正常退出旧实例，含托盘。
  3. 双击「独立代理启动器」。首次探测可能需要数秒。
  4. 客户端打开后，查看模型列表并发送简单问题。

日常快捷方式将控制台最小化，失败时显示中文提示。并未完全隐藏控制台，方便保留执行策略或脚本提前失败的信息。不强行结束任何旧实例。

如果 VPN 更换了端口，启动器会尝试重新寻找并验证可用的本机代理。若失败，使用网络诊断入口重新配置。原始官方启动入口始终保留。

06 / REAL ACCEPTANCE网络通过后，还要看真实回复

HTTPS 根路径返回 401、403 或 404，不等于模型已经恢复。建议在新的测试对话中逐轮发送：

1. 请只回复：连接测试成功。
2. 计算 17 × 19。
3. 请记住测试单词 launcher-check。
4. 刚才的测试单词是什么？
5. 用一句话总结这次测试。

确认每一轮都正常结束，没有反复重试。开发能力可在你新建的测试工作目录中，只创建和读取一个无敏感信息的小文件。不要让测试修改真实业务项目。

如果出现资格、地区、权限或额度限制，按官方规则处理。启动器不会改变这些限制。

07 / DIAGNOSE网络故障诊断

双击「独立代理启动器 网络诊断」或 03 网络故障诊断.bat，选择 1。工具比较五个公开 Google 域名的显式直连与代理连接，记录 DNS、TCP、TLS、HTTP 状态及耗时。

看到的结果如何理解
CONNECT 200，TLS 校验完成代理隧道与 TLS 传输本次完成；仍需验证账号和模型。
HTTP 401 / 403收到了服务器响应；可能涉及认证或权限，不能统一当作成功。
HTTP 404根路径不存在时也能返回 404；仅能说明服务器响应。
HTTP 000 / 超时请求未完成，查看代理、DNS、TLS 或网络状态。

结果仅保存在本机 logs/network-*.json。不上传日志，不记录 Token、Cookie、响应正文或聊天内容。Direct 表示明确不使用代理的对照，不代表所有 Windows 应用的默认网络行为。

08 / LOCAL PROXY手动填写自己的代理端口

  1. 在你使用的 VPN 客户端中查看「HTTP 代理端口」或「Mixed / 混合端口」。不要猜端口，也不要填订阅地址。
  2. 打开「独立代理启动器 网络诊断」，选择 2。
  3. 输入完整本机地址，例如 127.0.0.1:7890。这里的 7890 只是示例，应以你的 VPN 设置为准。
  4. 工具重新验证 CONNECT 与 Google TLS，通过后才保存。正常退出客户端并从专属入口重开。

支持 localhost:端口、127.0.0.1:端口、[::1]:端口。不接收密码、认证 URL、远程主机或额外参数。选择 3 可重新自动检测。

普通用户无需手动编辑 JSON。开发者可查看当前用户安装目录中的 config.json，不要将个人配置加入分享包。

09 / CLIENT UPDATES官方客户端更新后

先等待官方更新结束，使用官方方式完成更新；不强退、不替换官方文件。然后正常退出自动打开的实例，从专属入口重新启动。

启动器每次重新寻找当前可执行文件，常见原地更新通常无需重新部署。如果移动了客户端安装目录，可重新运行一键部署；自动识别失败时填写新路径。

官方日志显示下载中或状态未确认时，启动器会保守停止。先在官方客户端确认更新完成或明确失败。日志位置或格式改变、后台架构改变后，需要重新验证，不保证未来所有版本。

10 / TROUBLESHOOTING常见错误，先看具体原因

未发现可用代理 / VPN 未开启

检查 VPN 已连接且开启 HTTP/Mixed 本地监听。只有 SOCKS-only 时，本版不能直接使用；如果 VPN 不提供该功能，本工具无法凭空增加代理端口。

端口可连接，但不支持 CONNECT

可能填入了控制面板、API 管理或其他服务端口。返回 407 说明要求认证；本版不保存认证信息。

TLS handshake timeout / 证书验证失败

先运行诊断，看代理是否也失败。检查 VPN 连接和当前网络。证书验证失败时不要关闭校验或导入未知证书；联系网络管理员。

Antigravity 或语言服务仍在运行

等待当前任务与更新结束，通过应用菜单正常退出，包含托盘实例。启动器不会自动结束进程；无关软件也使用同名 language_server 时可能保守拦截。

客户端未安装 / 自定义路径未识别

先从官方渠道安装。部署时填写 Antigravity.exe 完整路径，不要填卸载程序或快捷方式本身。

同名快捷方式或安装目录归属不匹配

工具没有覆盖无关文件。将自己确认无关的同名入口改名后重试；不要随意删除未知目录。重新解压缺失的安装文件。

脚本、SmartScreen 或组织策略阻止运行

入口只为本次 PowerShell 进程指定执行策略，不修改系统或用户策略；组策略仍优先。不会绕过防护、应用控制或安全提示。核对来源及 SHA256 后按组织规范处理。

网络诊断通过，但模型仍不可用

区分服务端权限、地区资格、额度、模型故障和客户端兼容性。保留错误原文与发生时间，优先参考官方支持，不要通过本工具尝试绕过资格。

11 / UNINSTALL卸载与恢复原有启动方式

  1. 等待当前任务与更新结束，正常退出 Antigravity。
  2. 双击 04 卸载启动器.bat。如果解压目录已删除，在 %LOCALAPPDATA%\LocalProxyLauncher 中也有这个入口。
  3. 工具删除自己的运行文件和仍指向本安装的两个桌面快捷方式。被你改为其他目标的同名入口予以保留。
  4. 从原来的官方入口启动 Antigravity，即恢复原启动方式。

默认保留独立配置、配置备份和诊断日志，便于重新部署。不删除官方客户端、登录凭据、项目或聊天记录。没有系统代理、DNS 或注册表设置需要回滚。确认不再需要时，可以自行删除剩余的本工具目录。

12 / TRUST & LIMITS安全边界与兼容性

  • 仅修改启动进程的 HTTP_PROXY、HTTPS_PROXY、NO_PROXY；默认不设置 ALL_PROXY。保留本地回环通信。
  • 不修改官方程序、不注入或 Hook、不关防火墙或杀毒、不修改 hosts、DNS、注册表、证书或全局代理。
  • 不读取密码、Token、Cookie 或 VPN 密钥，不上传数据，不添加开机自启动。
  • 使用 Windows 自带 PowerShell 5.1、curl、.NET 和快捷方式接口，无额外依赖；日常错误提示使用系统 WinForms。
  • Windows 10 x64 与当前 MagicHut 环境有真实测试；Windows 11、其他 VPN、ARM64、受管设备和认证代理未完成实机覆盖。
  • 部分失败路径使用模拟测试，不能等同真实断网或所有更新状态覆盖。客户端真实回复与网络传输测试分开验收。
