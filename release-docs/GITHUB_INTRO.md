# GitHub 项目介绍

Local Proxy Launcher（独立代理启动器）是适配 Antigravity 的非官方 Windows 独立进程代理启动工具。使用系统 PowerShell、curl 和 .NET，提供代理发现、HTTPS CONNECT/TLS 验证、中文部署、独立启动、诊断与白名单卸载，不修改全局网络。

维护者：小路卡 XiaoLuka（XiaoLukaLab）。仓库：https://github.com/XiaoLukaLab/local-proxy-launcher 。当前：v1.0.0-beta.2 Pre-release；协议：MIT。本轮只更新账号、链接和发布元数据。

历史 QA：运行层 14/14，部署 6/7；末轮手动配置复验为 TLS 超时。Windows 11、其他 VPN、新入口真实模型回复尚待确认。不支持 SOCKS-only、远程认证与 PAC-only，不提供 VPN 或账号资格，不绕过服务限制。
